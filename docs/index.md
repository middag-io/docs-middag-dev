# MIDDAG Docs

The developer front of MIDDAG. Write your domain once, against contracts, not against the host. Run it in Moodle, WordPress, or standalone.

New here? Read [What is MIDDAG?](./about.md)

## Where to start

- **[MIDDAG Framework](./framework/index.md)**: platform-agnostic PHP with DI, PSR-15 HTTP, a query builder, forms, a command bus and Inertia. Apache-2.0.
- **[PHP Libraries](./libraries/index.md)**: the OSS (Apache-2.0) and internal (proprietary) libraries of the PHP family, with their versioning, compatibility, platform, documentation and guards.
- **[middag-react](./middag-react/latest/index.md)**: the React component library for the frontend side of a MIDDAG-based app.
